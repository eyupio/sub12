# Rifle catalog images

Drop CC-licensed JPGs/PNGs/WEBPs here, named `<make>-<model>.jpg` (lowercase, hyphenated, no calibre suffix unless it disambiguates a different SKU).

**Before adding an image:** read [../ATTRIBUTION.md](../ATTRIBUTION.md) and append a row recording the source URL, author, and licence. No image without an attribution row.

After adding `foo.jpg` here, set `image_url: '/catalog/rifles/foo.jpg'` on the matching entry in `frontend/src/catalog/rifleCatalog.ts`.

Suggested constraints: ≤200 KB, ≥256 px wide, neutral or transparent background where possible.
