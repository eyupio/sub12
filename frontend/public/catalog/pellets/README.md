# Pellet catalog images

Drop CC-licensed JPGs/PNGs/WEBPs here, named `<brand>-<model>.jpg` (lowercase, hyphenated; brand only, head size goes in metadata not filename).

**Before adding an image:** read [../ATTRIBUTION.md](../ATTRIBUTION.md) and append a row recording the source URL, author, and licence. No image without an attribution row.

After adding `foo.jpg` here, set `image_url: '/catalog/pellets/foo.jpg'` on one or more matching entries in `frontend/src/catalog/pelletCatalog.ts`.

Suggested constraints: ≤200 KB, ≥256 px wide, neutral or transparent background where possible.
